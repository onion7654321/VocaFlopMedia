# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/onion7654321/VocaFlopMedia/security/advisories/new) if enabled. If unavailable, open a public issue requesting a private reporting channel without disclosing the vulnerability itself.

Include the affected version, platform, impact and minimal reproduction steps. Remove cookies, credentials, personal paths, signed URLs and other private data from all attachments. Do not publish exploit details or test against systems without authorization.

## Release integrity

Release archives include SHA256SUMS.txt. Compare the downloaded file against the corresponding entry. A checksum detects corruption but does not substitute for publisher authentication or code signing. Current packages are unsigned; macOS notarization is not configured.

No fixed response time or support lifecycle is promised.
